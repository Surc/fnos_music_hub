# 歌曲下载模块

已实现 Hot 薄适配、持久化投递/幂等、重启回读、暂停恢复重试、实际音频校验和授权文件读取。当前只开放酷我；真实下载受到当前环境地区限制。

内部划分接单与授权、Hot 引擎适配、任务记录/恢复、文件校验、资产授权与入库请求。Hot 持有实际执行队列；门面不另建竞争调度器。
