# 歌单推荐模块

已实现 Hot HTTP 公共歌曲搜索与本地收藏门面，搜索不探测链接；缺音质和未知项仍保留。推荐和远端歌单适配尚未完成。

实现公共目录与账号推荐的统一门面、来源能力、元数据、收藏和完整快照。

内部按公共 CatalogProvider、账号业务 Provider、本地歌单/收藏、推荐排序与快照导出划分代码包；具体目录在选择运行语言后确定。QQMusicApi、MusicBox、music-lib 是不同职责的候选，不能全当作完整即用服务。

只交付完整有序的清单给下载模块，保留重复和未知项；搜索与浏览不依赖链接探测。遵守 [接口草案](../../docs/CONTRACTS.md) 与 [账号边界](../../docs/ACCOUNTS_AND_FEEDBACK.md)。
