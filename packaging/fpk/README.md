# 原生 FPK 交付目标

当前没有 build.sh、安装脚本或可安装包，不提供占位的“构建成功”。目标为 J4125 / x86_64 飞牛 NAS，无需 Docker，NAS 不安装 Rust/Go 编译器。

实现前明确独立应用 ID、配置/数据目录、非 root 进程边界与实际运行依赖。保留必要异语言进程，构建端产出可复现二进制；资源开销需实测。

安装/升级/停用/卸载均检测官方音乐状态、唯一 Socket 所有者、备份与恢复。配置和凭据迁移独立处理；打包排除登录态、历史、收藏、音频、日志和临时 URL。

正式发布记录构建提交、VERSION/tag、组件 SHA、包内容、正式附件 SHA256 与 NAS 验收。详见 [迁移说明](../../docs/MIGRATION.md) 和 [验证记录](../../docs/VALIDATION.md)。
