# 功能点验收清单

更新：2026-10-21，对应 `0.1.0a1` 开发分支。列为“已实现”不代表真实 NAS 已通过。平台、地区限制与本地复测见 [平台验收清单](ACCEPTANCE_PLATFORMS.md)，界面提案见 [界面评审稿](UI_REVIEW.md)。

## 状态与证据

实现状态：**已实现 / 部分实现 / 未实现 / 可选**。验收结果：**通过 / 失败 / 环境受限 / 待执行 / 不适用**；不适用须说明理由。自动检查、真实平台、NAS、客户端、FPK 分开签收，mock/生成音频不签收真实音乐下载。

“当前证据”描述截至本日期已有结果，**用户本地验收均待填写**。已有 20 项 Python、2 项 jsdom 检查的范围见 [验证记录](VALIDATION.md)，不折算为本表逐项通过数量。
