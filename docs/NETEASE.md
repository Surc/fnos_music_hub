# 网易只读目录与账号隔离

2026-10-24，基于 main `04677d32b96a0b824c2148001458d581f9f8f22c`。实现属于开发分支；真实网易账号与 NAS 尚未验收，未发布 FPK。

## 方案与来源

沿用旧工程已经使用的 MusicBox 协议，不引入第二套常驻音乐服务。固定 `darknessomi/musicbox` / `NetEase-MusicBox 0.5.3` 的提交 `9c405f4bae2384d0410e63f8b816a707553d72d3`，MIT；上游源码零修改。Hub 自有适配器保留其请求构造、WEAPI/EAPI 加密和目录接口，外围增加结构校验、错误分类和隔离。

比较过旧工程 `Surc/fnos_music_ext` 的 main `1d8f4e73945ae51a21cb5bce2202a3f9ee9d4ef6`：`musicbox-service/netease_ext.py` 的账号探测、歌单 ID→批量详情，以及 `discovery.py` 的公开歌单、本人列表和推荐入口可作接口依据。其进程全局 API/XDG、小时级 HTTP 缓存、重复 ID 合并与可播放过滤不适用于 Hub，因此没有复制该运行代码或复用旧服务的共享账号。继续保留旧工程双来源采用基线。api-enhanced 仍为替换评估参考，本轮没有混入它的协议。

NEMbox 导入本身会创建全局 XDG 文件，故不在 Hub 进程内导入。每次读取按需启动一个短进程，使用独立临时 0700 XDG 目录；凭据经标准输入传递，不放在命令行、环境变量或响应。外围 Session 在内存中持有 Cookie，不使用上游磁盘 CachedSession，不保存响应 Cookie，不发起刷新、取流、云端写入或反馈。请求前后核对实际 UID，返回 Hub 后重验本地会话和冻结账号授权。最多 4 个并行进程，每次 45 秒总超时，单 HTTP 响应最多 4 MiB，进程输出最多 2 MiB；超时/取消杀死并回收进程，再清理临时目录。目录使用直连、TLS 正常校验、拒绝重定向，不添加来源伪造 IP 头。

## 开启和账号操作

开发机安装 `python -m pip install -r requirements-netease.lock`，配置 `netease_enabled=true` 后重启 Hub。基础模式默认 false，缺固定版本依赖时拒绝启用；NAS 使用开发机构建好的依赖 wheel，不要求 Node、Docker 或编译器。网易目录只依赖可信飞牛身份，不要求为该用户启动 Hot；QQ 和酷我仍使用原逐用户 Hot 授权。

前台“我的与平台账号”→网易→关联网易账号：在当前同源页面的密码输入框提交本人登录 Cookie，服务端验证 UID；核对 UID/昵称后点击确认关联。当前只有 Cookie 导入，未实现网易扫码或密码登录；不要把 Cookie 发到聊天、Git、故障截图或日志。

第一次验证只保存 180 秒、当前飞牛会话所属的加密候选，没有私人目录授权。显式绑定再次核对 UID，账号与完成记录在同一 SQLite 事务提交。账号、尝试按 `{instance_id,user_guid,provider}` 隔离；凭据由现有 vault 二次加密后存入原 accounts 表，接口只返回不透明 AccountRef、UID、昵称、状态、binding_generation 和 credential_revision。schema 仍为 3，无新表。

“更新网易凭据”只允许同 UID，保持 AccountRef/绑定代次，递增凭据修订；不同 UID 明确拒绝，须先解绑再换号。解绑递增代次、删除加密凭据与候选，清理临时网易歌曲元数据；已明确收藏的本地歌曲独立保留，不等于云端收藏。退出飞牛撤销本会话候选及在途读取，保留已经完成的关联；另一个用户或会话的尝试不被继承。

## 只读目录

| 能力 | 行为与界限 |
| --- | --- |
| 公开歌单 | MusicBox top_playlists，30 项/页，沿来源 more；使用空 Cookie，即使当前已关联 |
| 本人歌单 | 按已验证 UID 读取创建与收藏的列表，30 项/页，保留未知摘要；不接受前台指定另一个 UID |
| 推荐歌单 | MusicBox recommend_resource，只称账号推荐，personalization=unverified |
| 推荐歌曲 | MusicBox recommend_playlist 对应 `/weapi/v3/discovery/recommend/songs`；前台仍称账号推荐歌曲，真实每日更新/个性化效果待对照来源客户端 |
| 歌单详情 | 来源 trackIds 与 trackCount 一致后按 100 项切页，详情请求可合并重复 ID，输出按原始位置重建；重复、未知、缺详情和不可播放歌曲均保留，不探测歌曲链接 |
| 本地收藏 | 复用 owner/TrackRef 与原收藏机制，`provider=netease/id_type=songid/id` 字符串；不写云端 |

推荐接口返回的有界列表按 30 项分页展示，每次重新读取；没有已验证的稳定上游版本。详情总数上限 10000，缺 ID/总数不一致、超容量或来源截断明确失败，不拼接旧页，也不宣称读完了完整歌单。所有目录保持 `complete=false/integrity=page_only`，没有新增网易完整快照；QQ 两轮快照继续独立工作。

分页失败保留前一页及重试页码；不缓存完整私人目录响应，禁止 SDK 的持久 HTTP 缓存。只有读取成功且账号/代次/修订与会话仍有效，才将白名单歌曲元数据存入本 owner 的原 songs 表供本地收藏。解绑、重绑、更新凭据或退出期间的旧成功/错误响应均不得发布或回写；旧错误不能把新账号标为过期。普通平台失效用 409 `platform_auth_required`，飞牛会话失效用 401；限流 429，暂时不可用 503，协议异常 502，截断/incomplete 409。私人失效不回退匿名，也不退出正常飞牛会话。

网易搜索、扫码、完整快照、下载、云端喜欢/订阅写入与真实播放反馈未开放。目录能浏览、显式选曲能保存本地清单均不解禁下载；服务端任务准入继续只允许酷我。
