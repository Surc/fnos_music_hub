## 使用与验收边界

Linux amd64 原生包，应用/包用户 fnos_music_hub，非 root，无需 NAS 安装 Docker、编译器、系统 Python 或 Node。需要已有音桥 API 和 HTTPS 根地址反代到 127.0.0.1:8790；首次 users 为空，按可信 GUID 配置逐用户 Hot。网易/QQ 账号默认关闭，网易/QQ 下载、云端写入、入库、Socket 注入和可靠播放反馈未开放。

本机 WSL 的两个固定酷我样本真实下载技术校验见 [本地报告](../HOT_LOCAL_RETEST_20261026.md)；它使用独立开发构建，不代替该 FPK 的真实 NAS 验收。原环境 407 历史保留。J4125/fnOS 安装升级、NAS 重启、真实双用户/账号、ACL、CPU/RSS/磁盘与录音人工试听仍待验收。
