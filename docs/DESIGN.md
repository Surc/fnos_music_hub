2026-10-24：网易目录已采用可选固定 MusicBox 库的开发适配，每次短进程隔离全局 XDG/单例；没有新常驻服务或 Hot 上游补丁。只读能力与真实待验见 [网易模块](NETEASE.md)，下述总体目标的未实现项不因目录接入而解禁。

日期：2026-10-22。状态：设计基线 v0.1；已开始核心链路开发，实现范围见 [迭代记录](ITERATION.md)。

本文件将 v1.6 研究第十八、十九节的修订收敛为新工程目标。研究中“以旧 ext 为应用壳”在此解释为复用经过核对的界面与生命周期组件；新仓库不继续在旧工程中堆叠全部运行栈。

## 三个业务模块

| 模块 | 负责 | 边界 |
| --- | --- | --- |
| 歌单推荐 | 网易/QQ/酷我公共歌单、分类、榜单、搜索、详情；个人推荐、本地收藏、明确云端操作 | 只提供元数据和不可变下载清单，不管理下载队列 |
| 歌曲下载 | 接单幂等、任务归属、引擎适配、实际文件校验、资产管理、入库请求 | Hot 执行下载调度；不自行实现平台歌单推荐 |
| 飞牛音乐注入 | 可选在线资源展示、代理与 Socket 接管/恢复、管理员设置 | 与身份/曲库适配解耦，停用注入不关闭独立前台 |

身份、平台账号、资产授权和反馈作为共享代码包组织。先做单个应用门面与必要的异语言适配进程，不为每个内部组件建立常驻服务。当前网关为 Python/FastAPI，QQMusicApi 按需作为固定版本 Python 库启用，不另起常驻服务；Hot 仍是逐用户原生进程。QQ 实现边界见 [账号模块](QQ_ACCOUNTS.md)。

## 组件与主上游

| 组件 | 主上游候选 | 本工程负责的适配 / 准入条件 |
| --- | --- | --- |
| QQ/酷我下载引擎 | HotDownloader | 保留核心搜索/队列/歌词标签/下载；补逐账号上下文与任务归属，不能沿用全局 QQ 凭据 |
| QQ 账号推荐/收藏 | QQMusicApi | 不竞争登录刷新；只读取账号门面交付的凭据快照，确认私人接口真实使用本人账号 |
| QQ 登录/刷新协议 | HotDownloader | 单一刷新所有者；从已有凭据 Store 扩展逐账号隔离，验证字段转换 |
| 网易账号与目录协议 | MusicBox（现有基础） | 验证账号隔离；反馈/订阅存在缺口，先小扩展或整体替换评估 |
| QQ/酷我公共目录 | music-lib（有条件） | 先验证保序、分页、重复、未知项；不通过时不开放“整单完整下载” |
| FnIdentity / FnLibrary | 音桥 fn-music-bridge | 同一主上游；补严格 GUID 归属、授权和认证事件导出 |
| 注入 / Socket 生命周期 | fnos_music_ext | 提取边界内组件，独立应用 ID 与兼容检测；一个 Socket 一个接管者 |
| 真实收听会话与平台反馈 | 本工程门面 + 对应平台协议组件 | 按身份/设备/会话累计可信区间；不会把 fnmusic-sync 的估算时长直接上报 |

“主上游”是协议维护责任，不表示所有组件现在都必须安装。同一上游可以支撑多个组件。TuneWeave 的酷我私人账号仅列可选验证；go-music-dl 用于对比；酷狗、咪咕、汽水、洛雪与聚合资源不自动进入一期。

## 前台目标

用户前台包含“发现/推荐”“我的歌单与收藏”“下载任务”“已下载歌曲”和“我的平台账号”。公共候选池可以共享，但私人排序、排除项、缓存、收藏、账号状态和任务必须按飞牛用户隔离。

“为我推荐的歌单”与“每日推荐歌曲”分开显示；热门歌单不标为个人推荐。歌单卡片标明来源、公共/本人账号/共享账号、收藏方式和可用能力。来源登录不支持的动作不显示为可用。

管理员设置单独包含注入开关、兼容状态、下载允许目录、入库目标及故障恢复。普通用户只能选择被授权的目标。下载目录属于文件存储配置，飞牛音乐库属于索引目标，两者不能混为一个配置项。

已下载页面分别展示下载、校验、文件位置、来源/格式、入库结果。搜索歌曲始终保留元数据，链接失败、会员或音质不足均显示明确状态；跨平台匹配需要版本/时长验证和实际来源记录。

## 部署与迁移

目标 J4125 / x86_64 / 8GB，原生 FPK，不要求 NAS 装编译器或 Docker。音桥若保留 api/service 结构更便于更新，允许保留必要进程；资源预算以实测决定。

第一版先完成严格认证与最小歌曲链路，再做账号推荐和完整歌单。实际代码接入后再选择许可证、运行依赖与应用 ID，形成可复现构建。迁移规则见 [迁移说明](MIGRATION.md)，验收顺序见 [迭代计划](ITERATION.md)。
