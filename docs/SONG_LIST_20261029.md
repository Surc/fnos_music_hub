# 歌曲列表与品质筛选

2026-10-29。用户要求将歌曲卡片改为接近HotDownloader的行列表，并展示格式、大小和品质标签、支持按品质排序筛选；随后明确要求先不更新NAS。

每首歌按行显示歌曲、歌手、专辑、来源、分秒时长与操作。每档品质展示标签（标准/HQ/SQ/Hi-Res或来源原标签）、格式与来源大小；size=0/缺失显示“大小未提供”，无法识别格式显示“格式未提供”。未取流、不估算文件大小，也不将搜索元数据当成实际音频校验。多档品质始终与对应格式/大小放在同一个标签中。

搜索提供全部/指定/品质未提供筛选，点击歌曲品质标签也可筛选；按歌曲的最高已知品质升序/降序，未知排最后、同档稳定排序，可恢复来源顺序。显示“当前显示/已加载”数量；继续加载时沿用筛选与排序，不声称对尚未加载的全平台结果排序。筛选不改变下载确认中的品质准入。

稳定行ID保留合法重复项和选中状态。筛选隐藏的选中项保留但明确提示不会提交，批量下载只包含当前显示的选中行。退出清理筛选；旋转与低高度只重排，不重新认证/搜索/提交。收藏和QQ/网易目录共用行展示，歌单/推荐/快照的原始顺序与保存内容不被搜索排序修改。

数据沿用固定Hot `07e86c3d06243cf1350925c0dd3be704005abd29` 的QualityItem/品质顺序契约与现有Hub归一化响应；没有改上游、适配器、账号、协议基线或下载队列。QQ/网易/其他品质的下载能力未因此开放。
