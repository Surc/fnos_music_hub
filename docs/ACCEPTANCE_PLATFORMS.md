## 用户本地复测步骤

1. 按 [原生启动说明](RUNNING.md) 部署待测 Hub、音桥及逐用户 Hot，先验真实 A/B 身份。记录版本；换了 Hot 提交/构建则作为新组合，不能说与历史二进制一致。
2. 在相同环境/账号上下文/固定 RID/320kmp3/降级策略下，对照 Hot 原生链路与 Hub 适配链路；分别保留 HTTP/业务码及任务结果。两个样本独立填报，不以同名其他录音替代。
3. Hub 页面：登录→酷我搜索→确认 RID/歌手/版本→提交→任务终态→已下载文件。验证实际容器/编码/码率/时长、完整解码、SHA256，试听确认录音。历史时长仅参考；来源元数据更新单独记。
4. 测 A/B 收藏/任务/文件隔离及 Hub/Hot 重启恢复。目录有文件不等于飞牛已索引，当前入库仍 unsupported。
5. 用下表判定，追加脱敏报告。会员/其他音质另开用例；无完整验证资产不能签收下载。

| 同环境结果 | 判定与下一步 |
| --- | --- |
| Hot 与 Hub 均地区限制 | 本地仍环境受限，保留来源错误，不算通过 |
| Hot 成功、Hub 失败 | 核对版本/账号/音质/目录/参数，立适配或授权问题，不归因地区 |
| 两者均取得正确且校验通过的完整音频 | 该样本/版本/环境通过，不推广全平台/音质 |
| 只有搜索/临时 URL/文件名/试听或损坏音频 | 下载未通过，记实际原因 |
| 未执行或组合不可比 | 待执行或新组合待验证，不签收 |

开发机工具 `scripts/live_hot_smoke.py` 当前需要固定源码目录下的 `crates/hotdownloader-server/target/debug/hotdownloader-server`，不是适配所有 NAS 发行二进制的安装脚本。NAS 无需编译器；按 RUNNING 原生部署和页面流程测试，原始日志/音频不进 Git。
