# 独立前台

当前已有原生 HTML/CSS/JavaScript 开发界面，静态资源与后端同源提供，不需要 NAS 安装 Node。

支持飞牛登录、酷我/QQ 公共搜索、本地收藏、酷我下载任务、已验证文件管理和只读管理员注入状态。平台账号、推荐歌单、云端收藏与注入开关尚未开放，界面明确标示当前能力。

没有浏览器 user_id 切换或 localStorage token；用户身份由服务器验证。jsdom 覆盖搜索文本/XSS、稳定引用提交、CSRF、退出清屏与非管理员入口；真实浏览器和 NAS 体验仍需验收。

布局与范围见 [当前设计](../../docs/DESIGN.md)，运行方式见 [启动说明](../../docs/RUNNING.md)。
