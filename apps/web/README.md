# 独立前台

2026-10-29：歌曲使用行列表，展示每档品质的标签、来源格式和大小。搜索增加品质筛选、最高品质升降序/来源顺序；点击品质标签也可筛选。只处理已加载的搜索结果，歌单/快照保留原顺序。缺失大小显示未提供，来源宣称的品质不代表已校验音频。本轮未升级NAS。

QQ 可选能力已接扫码/显式关联、推荐歌单/猜你喜欢与本人歌单分页；不展示共享或原型账号数据。按 [QQ 实施](../../docs/QQ_ACCOUNTS.md) 区分受控检查与真实平台/NAS 验收。

当前已有原生 HTML/CSS/JavaScript 开发界面，静态资源与后端同源提供，不需要 NAS 安装 Node。

支持飞牛登录、酷我/QQ 公共搜索、本地收藏、批量选曲、下载确认（音质/授权目录）、任务/文件双标签、状态/文件筛选、失败及文件详情、本人平台能力页、管理员目录/曲库只读页与独立注入状态。平台账号、推荐歌单、云端收藏与注入开关尚未开放，界面明确标示当前能力。

没有浏览器 user_id 切换或 localStorage token；用户身份由服务器验证。jsdom 覆盖稳定引用、保序重复、确认幂等/丢响应、退出清屏、迟到请求与换号、权限和能力状态。`npm run test:browser` 使用 Chromium 与合成同源 API 检查十种视口；不等于真实 NAS 或平台验收。

布局与范围见 [当前设计](../../docs/DESIGN.md)，运行方式见 [启动说明](../../docs/RUNNING.md)。

PC 横/竖屏与窄窗、手机竖屏底栏和横屏侧栏均已实现。旋转不重建页面或下载确认表单；弹层按可见视口和布局高度共同约束，正文滚动、确认/关闭可达。Node、jsdom、Playwright 仅用于开发/CI，NAS 不安装这些依赖。
